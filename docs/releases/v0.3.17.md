# AG Relay 0.3.17

## 修复 Codex 会话绑定失效后的旧对话续聊

- 仅当 Codex 的 `/v1/responses` 请求明确返回 `session_binding_invalidated`（HTTP 409／400，或 HTTP 200 响应体中的错误载体）时，网关才对本次请求尝试一次恢复：只移除历史条目的顶层 `id`。
- 恢复保留全部 reasoning 加密内容与可读摘要、消息、工具名称／参数／结果及 `call_id`、搜索条目与内容；客户端身份头、`client_metadata`、`prompt_cache_key` 和模型身份原样转发。
- 正常首发请求不新增清理，不扩大 Claude 策略，也不把本次恢复登记进会删除推理的旧兼容缓存。恢复失败时不会自动升级为丢弃整条推理的处理。
- 只在尚未向客户端交付内容或工具时尝试恢复；已交付后不重放整条请求，避免重复输出或执行工具。

## 使用提醒

- 本次只覆盖已明确识别的一次性恢复，不保证所有上游错误或所有 `30013` 情形都能恢复；仍然失败时，客户端可能需要重新开始对话。
- 重试次数、等待时间、历史兼容策略和其他请求路径保持不变。
- 请等当前任务结束后再通过应用内更新升级；安装器不会强行结束正在工作的网关。
